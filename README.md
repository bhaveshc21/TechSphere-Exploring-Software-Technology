# 🌐 TechSphere – Exploring Software & Technology

TechSphere is an educational and interactive website developed as a **Web Page Designing (WPD) Microproject** using HTML.

The website provides information about different areas of software and technology through a collection of simple, user-friendly web pages. It is designed to help students and beginners understand concepts related to software, operating systems, web browsers, devices, programming languages, and productivity tools.

## 📌 Project Overview

TechSphere brings different technology-related topics together in one website.

The project demonstrates the use of **HTML-based web page designing** to create a structured and interactive website with multiple interconnected pages.

It includes informational pages, a quiz section, login/signup pages, feedback functionality, and contact information.

## ✨ Features

- 🏠 Home page with project navigation
- 📖 About page describing the website
- 💻 Information about different types of software
- 🖥️ Operating Systems information
- 🌐 Web Browsers information
- 📱 Information about different devices
- 🎓 Educational Software section
- 📊 Productivity Software section
- 👨‍💻 Programming Languages section
- 🧩 Interactive Quiz section
- 🔐 Login and Signup pages
- 💬 Feedback page
- 📧 Contact page
- 🔗 Navigation between multiple web pages
- 📚 Educational and beginner-friendly content
